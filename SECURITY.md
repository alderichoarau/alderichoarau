# Security Policy

This repository only contains my [GitHub profile README](README.md) ([🇫🇷 French version](README.fr.md)) and the automation that maintains it (dependency updates via Dependabot, a link-checker workflow). There is no application code or user data here.

## Reporting a Vulnerability

If you spot a security issue with one of the GitHub Actions workflows or dependencies used in this repository (e.g. a compromised action, an overly broad permission), please **do not open a public issue**. Instead, report it privately via [GitHub Security Advisories](https://github.com/alderichoarau/alderichoarau/security/advisories/new).

I'll acknowledge reports within a few business days.
